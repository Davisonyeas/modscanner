# Installation

## pip

Install ModScanner from PyPI:

```bash
pip install modscanner
```

using uv:
```bash
uv add modscanner
```

Verify installation:
```bash
modscanner --help
```

Check the installed version:
```bash
modscanner version
```

---
## Development Installation
Clone the repository
```bash
git clone https://github.com/davisonyeas/modscanner.git
cd modscanner
```

Activat the environment
```bash
source .venv/bin/activate
```

Run the tests:
```bash
pytest -v
```
